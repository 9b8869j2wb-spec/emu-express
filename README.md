# Emu Express

An outback touch-typing game for the classroom. Ride an emu from Uluru to Perth, one set of keys at a time.

Play: https://9b8869j2wb-spec.github.io/emu-express/

- Works with a keyboard or the iPad on-screen keyboard (tablet mode).
- Progress is kept as a short code students write down, such as `EMU-2225-T`. Nothing is sent anywhere.
- A dingo chases the emu when typing slows down. If it catches up, the stage starts again (Off, Easy, Normal or Hard, set at the bottom of the page).
- A single `index.html` with no build step.
